# ReplaceDBlock — интеграция и подмена динамического блока

AutoLISP + COM для AutoCAD. Команда `ПОДМЕНАБЛОКА` (латинские алиасы: `RDB`, `RepDblock`, `ПДБ`, `INTEGRATE`) берёт из буфера обмена новую
итерацию семейства динамических блоков и заменяет ею все вхождения старых
итераций в текущем чертеже: создаёт недостающие варианты, обновляет общие
вложенные определения по всему чертежу, возвращает видимость вложенных блоков
и динамические свойства, сохраняет суффиксы вариантов и чистит старые
определения. Отчёт последнего прогона доступен командой `RDBREPORT` и
сохраняется в `RDBREPORT.txt` рядом с чертежом.

Текущая сборка: **72.7**.

## Команды

Основная — `ПОДМЕНАБЛОКА` (латинские алиасы: `RDB`, `RepDblock`, `ПДБ`, `INTEGRATE`).
Запускается из буфера обмена без дополнительных запросов.

| Команда | Что делает |
|---|---|
| `ПДБ / ПОДМЕНАБЛОКА (RDB)` | Заменить все старые вхождения семейства новой итерацией из буфера |
| `ПДБВЫБОР` (`RDBPICK`) | Подмена по мастер-блоку, выбранному на чертеже |
| `ПДБОЧИСТКА` (`RDBCLEANUP`) | Многопроходная очистка старых определений |
| `ПДБВОССТАНОВЛЕНИЕ` (`RDBRECOVER`) | Восстановление после сбоя |
| `ПДБЛЕЧЕНИЕ` (`RDBHEAL`) | Лечение паспортов динамики |

Остальные команды диагностики и тестов — в `docs/README.md`.

## Как прогнать

Коротко: в файле-доноре скопировать мастер-блок (`Ctrl+C`), в
файле-реципиенте загрузить `RepDblock.lsp` и выполнить `ПОДМЕНАБЛОКА` (или `RDB`, `ПДБ`, `INTEGRATE`).
Полный порядок с пометкой активного чертежа на каждом шаге — в
`docs/ИНСТРУКЦИЯ_ПРОГОН.md`.

## Тесты

Тесты не требуют AutoCAD: `tests/autolisp.py` — интерпретатор подмножества
AutoLISP, который исполняет реальный `RepDblock.lsp` с подменёнными
адаптерами чертежа. Раздел 8 (исполняющий слой AutoCAD) при этом не
загружается.

```
python3 tests/run_tests.py         # 824 проверки
python3 tests/run_space_tests.py   # 59 проверок
python3 tests/check_load.py        # 54 команды/алиаса, 344 имени
python3 tools/lint_parens.py RepDblock.lsp
python3 tools/check_arity.py RepDblock.lsp
python3 tools/check_acad_funcs.py RepDblock.lsp
```

`check_load.py` грузит файл с `KG-TESTING = nil` и проверяет, что в разделе 8
нет вызовов неопределённых имён и что баннер перечисляет все команды.
`check_arity` проверяет 372 определения, `check_acad_funcs` — 558 вызовов.

## Что не проверено в AutoCAD

Стенд не покрывает то, что существует только в живом чертеже: настоящие
COM-вызовы, `entmod`/`entupd`, очистку через `PURGE`, чтение имени параметра
видимости из словаря определения (`ACAD_ENHANCEDBLOCK`, группа 301). Перечень
— в конце `docs/README.md`.
